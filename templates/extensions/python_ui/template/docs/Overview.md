# Overview

This extension demonstrates a small OpenUSD workflow:

- Create cube, sphere, cylinder, and cone prims under `/World`.
- Select the newly created prim in the stage.
- Edit its position and scale from the extension window.
- Generate a parameterized clean-energy grid with substations, connections,
  solar, wind, and battery-storage nodes.
- Generate a conceptual 3D nanoprint fab with cleanroom, material, inspection,
  and configurable printer-bay stations.
- Open `data/openusd_product_demo.usda` as a starter OpenUSD product scene.

The grid is a planning visualization, not an engineering certification. Real
deployments still require electrical studies, interconnection analysis,
permitting, environmental review, and professional engineering.

The nanoprint fab is a conceptual production-layout model, not a validated
nanofabrication process or manufacturing specification.
